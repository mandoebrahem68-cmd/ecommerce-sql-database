# E-Commerce Database Schema (SQL Script)

A fully normalized (3NF) relational database schema designed for an E-Commerce platform.

## Features
- **Users Management:** Stores customer credentials and profiles.
- **Product Catalog:** Categories and products with inventory control.
- **Orders & Items:** Tracks user orders and multi-item checkouts.
- **Payments:** Handles order status and payment methods.

## How to Use
1. Download the `ecommerce_database.sql` file.
2. Open your database management tool (MySQL Workbench, pgAdmin, or SSMS).
3. Import and run the script to generate the database structure and sample data.
